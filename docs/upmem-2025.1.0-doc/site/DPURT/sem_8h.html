Detailed Description

Synchronization with semaphores.

A semaphore is characterized by a counter and a wait queue. It provides two functions:

  • Take: the counter is decremented by 1. If the counter is negative, the thread is blocked (stop) and placed in the semaphore's wait queue, waiting to be resume by another thread.
  • Give: the counter is incremented by 1. If the counter was negative before the increment, the thread resumes the execution of the first thread waiting in the waiting queue. In all the cases, the thread continues its own execution.
