COUNT_SAME 

keep the previous configuration

COUNT_CYCLES 

switch to counting clock cycles

COUNT_INSTRUCTIONS 

switch to counting executed instructions

COUNT_NOTHING 

does not count anything

COUNT_DISABLE_BOTH 

disable performance counters (v1B only)

COUNT_ENABLE_BOTH
