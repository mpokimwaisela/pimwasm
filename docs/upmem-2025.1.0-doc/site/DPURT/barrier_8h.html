Detailed Description

Synchronization with barriers.

This synchronization mechanism allows to suspend a fixed number of tasklets until the expected number of subscribers is present. When the required number of tasklets reached the barrier, the counter of the barrier will be reinitialised to the original value.

void barrier_wait ( barrier_t *  barrier)

Decrements the counter associated to the barrier and suspends the invoking tasklet.

The counter of the barrier is decremented and the invoking tasklet is suspended until the counter associated to the barrier is reduced to 0.
