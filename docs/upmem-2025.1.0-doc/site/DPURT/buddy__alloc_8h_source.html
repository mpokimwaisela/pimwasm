28 /*
29  * @internal The algorithm used in this implementation is Buddy memory allocation.
30  *
31  * A particularity of this implementation is that no headers are created and thereby
32  * the memory consumption of the heap is reduced. The drawback is a slight slow-down
33  * in speed of memory freeing.
34  *
35  * Warning :
36  * Due to the particularities of the implementation (lack of headers), <code>buddy_free</code>
37  * will always try to find a pointer to free. If the pointer given in the parameter
38  * is not currently allocated by <code>buddy_alloc</code> or <code>buddy_realloc</code>, <code>buddy_free</code>
39  * will do nothing.
40  *
41  */
