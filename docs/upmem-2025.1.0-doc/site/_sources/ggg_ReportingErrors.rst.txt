Reporting errors
================

To report errors, please send an email to ``support@upmem.com``.

If the error is raised by ``dpu-upmem-dpurte-clang``, we would ask you to join a report generated by the tool as follows:

  * Execute the command, specifying the ``-save-temps`` option
  * As a result, ``dpu-upmem-dpurte-clang`` generates some files into the working directory
  * Compress this directory and attach the archive to the bug submission

The support team may also request for a "diagnostic of your environment":

  * Invoke ``dpu-diag`` from a terminal and store the result into a file (e.g. ``dpu-diag > diagnostic.txt``)
  * Attach the result to the bug submission
