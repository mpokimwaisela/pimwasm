Fetches the internal context for each thread of the DPU.

dpu_extract_pcs_for_dpu or dpu_initialize_fault_process_for_dpu must have been called before calling this function. This function extracts the working register values, the carry and zero flags for each thread, and also the atomic register values for the DPU.

Parameters
dputhe unique identifier of the dpu
contextthe debug context which will store the internal context of all threads
Returns
Whether the operation was successful.
