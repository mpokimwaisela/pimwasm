Detailed Description

General purpose ELF loader, able to load and map any section.

Purpose of this loader is to provide an easy to use interface to upper level applications, in particular from Java world, with functions to load and read ELF files, getting sections and associated symbols in a map-like form.

The first operation consists of loading the ELF file, using dpu_elf_open, or directly from memory, using dpu_elf_map. Both functions return a "DPU elf descriptor". The descriptor is used as reference to other functions and must be deleted with dpu_elf_close when finished.

The information extracted from a file are:

  • The list of sections (dpu_elf_get_sections)
  • The contents of a given section (dpu_elf_load_section)
  • The symbols defined in a given section (dpu_elf_load_symbols)
  • The runtime information fetched from symbols (dpu_elf_get_runtime_info)

typedef void* dpu_elf_file_t

A "file pointer" to an ELF file.

Such a descriptor is created by dpu_elf_load_file, as a reference for subsequent requests. It must be destroyed with dpu_elf_delete.
